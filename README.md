## 🚀 Fitur Unggulan
- **Next.js 14 App Router**: SSR aman, bebas hydration mismatch (`mounted` protection).
- **Running Marquee Ticker**: Pengumuman event bergerak otomatis.
- **Hitung Mundur WIB**: Countdown digital menuju Jumat, 27 November 2026 pukul 07:00 WIB.
- **Katalog & Filter**: Pencarian instan, filter kategori (Semua, Makanan, Minuman), urutkan harga termurah/termahal.
- **Keranjang Belanja**: Global state, stepper kuantitas langsung di kartu, konfirmasi hapus, tersimpan aman di `localStorage`.
- **Checkout & WhatsApp Otomatis**: Form tervalidasi, pembuatan ID unik `BB-20261127-XXXX`, dan tombol otomatis membuka WhatsApp Admin Nisrina (`6285843788915`).
- **Generator Struk Digital Thermal**: Pilihan ukuran 58mm & 80mm, unduh PDF (`jsPDF`), cetak thermal langsung (`window.print()`), dan salin pesan.
- **Dashboard POS Kasir (`/admin`)**: Dilindungi PIN `1212`, rekap omzet & porsi terjual, pembaruan status pesanan, dan input manual pesanan stand langsung (walk-in).
- **Floating WhatsApp**: Akses cepat ke Nisrina dari semua halaman.

## 💻 Panduan Menjalankan Secara Lokal

1. **Instal dependensi:**
   ```bash
   npm install
   ```

2. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

3. **Build untuk Produksi:**
   ```bash
   npm run build
   npm run start
   ```

---

## ☁️ Panduan Deploy ke Vercel (1-Click)
1. Push repository ini ke GitHub / GitLab.
2. Buka dashboard [Vercel](https://vercel.com) dan klik **Add New Project**.
3. Import repository `WEBSITE PKWU` (Framework Preset akan otomatis terdeteksi sebagai **Next.js**).
4. Klik **Deploy**! Proyek langsung live dengan domain gratis `.vercel.app`.
